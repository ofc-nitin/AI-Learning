# Deliverables

Everything the AI team produces lands here, in a folder per role:

| Folder | Owner |
|---|---|
| `product/` | Product Manager: specs, user stories, roadmaps |
| `research/` | Researcher: market, competitor and technical research |
| `design/` | Designer: flows, wireframes, HTML mockups, design tokens |
| `qa/` | QA Engineer: test plans and QA reports |
| `analysis/` | Analyst: reports, models, scripts, charts |
| `ops/` | Ops: runbooks, infrastructure docs, SOPs |
| `marketing/` | Marketing: positioning, copy, launch plans |
| `standups/` | Chief of Staff: weekly status reports |

Files are named `YYYY-MM-DD-short-slug.md`. Key decisions are logged in [`decisions.md`](decisions.md).
